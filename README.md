# Auto Mindmap - 视频字幕思维导图

一个 Chrome 浏览器插件，可以自动获取 **B站** 和 **YouTube** 视频的字幕，并使用大模型生成思维导图。

## 功能特性

- 🎬 **多平台支持**：同时支持 Bilibili 和 YouTube
- 🤖 **AI 智能总结**：自动下载字幕，用 AI 生成结构化思维导图
- 🔔 **悬浮球提醒**：实时显示生成进度，点击查看导图
- 📝 **仅获取字幕**：右键悬浮球 → 菜单「获取字幕」，只提取字幕（复制 / 下载 .txt），不消耗 LLM 调用
- 🎙️ **重新语音识别**：右键悬浮球 → 菜单「重新语音识别」，跳过官方字幕与全部缓存，对音频重跑 ASR（字幕面板、导图工具栏也有入口）
- ⚙️ **灵活配置**：支持自定义 Prompt、多个 LLM 配置、排除关键词等
- 🔌 **连接测试**：配置页一键发最小请求，直接看到「实际请求地址 + 模型 + 上游报错」，并列出该密钥可用的模型清单（点击即可切换）
- 💾 **本地缓存**：可选将导图保存到本地目录
- 🎤 **ASR 语音识别**：支持 B 站在无字幕时，通过本地 Whisper (GPU 加速) 自动识别语音
- 🧠 **双阶段反思模式**：支持“生成 &rarr; 评估并优化”两阶段流程，显著提升导图准确性。

## 安装与配置

由于本项目不包含编译后的文件，您需要手动构建插件：

### 1. 构建项目
```bash
# 安装依赖
npm install

# 执行编译（生成 dist 目录）
npm run build
```

### 2. 加载到 Chrome
1. 打开 Chrome 扩展管理页面：`chrome://extensions/`
2. 开启右上角的**「开发者模式」**
3. 点击**「加载已解压的扩展程序」**
4. 选择项目根目录下的 **`dist`** 文件夹

### 3. 初始化配置
1. 右键点击插件图标 → **选项**，打开设置页面。
2. 默认情况下，插件已内化了反思模式和基础 Prompt。
3. 您只需添加您的 LLM 配置（API 地址和密钥）并保存。
4. 访问 B站 或 YouTube 视频页面，即可自动开始生成。

### 4. 使用说明

- **自动生成**：打开视频页面后自动开始
- **手动生成**：点击悬浮球可查看导图或手动触发生成；已有字幕时直接基于该字幕生成，不重复下载/识别
- **仅获取字幕**：右键点击悬浮球弹出菜单 →「获取字幕」，只提取字幕并弹出结果面板，可一键复制或下载 .txt；本次观看的自动流程会跳过导图生成
- **重新语音识别**：右键菜单 →「重新语音识别」，忽略官方字幕与已有缓存，直接对音频重新识别（会清掉该视频的字幕/导图缓存）。字幕结果面板与导图查看器工具栏上也有同名按钮；识别完成后点击悬浮球即可用新字幕生成导图
- **暂停功能**：点击工具栏图标可暂停/恢复自动生成

### 支持的 LLM 提供商

配置页「大模型配置」→「LLM 提供商」内置以下预设（选择后自动填好地址与模型名，可再手动改）：

| 提供商 | API 地址（基址） | 模型示例 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta` | `gemini-1.5-flash` |
| 商汤 SenseNova | 内地 `https://token.sensenova.cn/v1` / 海外 `https://token.sensenova.ai/v1` | `sensenova-6.8-flash-lite` |
| Ollama | `http://localhost:11434/api` / `https://ollama.com/api` | `llama3` |
| LM Studio | `http://localhost:1234/v1` | 本地已加载模型名 |
| 自定义 | 任意 OpenAI 兼容基址 | 以服务商文档为准 |

> ⚠️ 报错 `HTTP 404: model route not found` 表示**上游找不到这个模型的调用路径**（密钥本身是通的，否则会是 401）：
> 常见原因有三种 —— ① 基址漏了 `/v1` 或填错地区域名；② 模型标识与服务商文档不一致；③ **上游把该模型改名/下线了**（预览版尤其容易发生，本地配置一个字没改也会突然 404）。
> 在配置页点「连接测试」：它会同时返回**该密钥当前可用的模型清单**（点一下即可填入模型名称），直接对照就能确认是不是第 ③ 种情况。
