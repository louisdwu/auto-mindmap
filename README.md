# Auto Mindmap - 视频字幕思维导图

一个 Chrome 浏览器插件，可以自动获取 **B站** 和 **YouTube** 视频的字幕，并使用大模型生成思维导图。

## 功能特性

- 🎬 **多平台支持**：同时支持 Bilibili 和 YouTube
- 🤖 **AI 智能总结**：自动下载字幕，用 AI 生成结构化思维导图
- 🔔 **悬浮球提醒**：实时显示生成进度，点击查看导图
- ⚙️ **灵活配置**：支持自定义 Prompt、多个 LLM 配置、排除关键词等
- 💾 **本地缓存**：可选将导图保存到本地目录
- 🎤 **ASR 语音识别**：支持 B 站在无字幕时，通过本地 Whisper (GPU 加速) 自动识别语音
- 🧠 **双阶段反思模式**：支持“生成 &rarr; 评估并优化”两阶段流程，显著提升导图准确性。

## 安装与配置

由于本项目不包含编译后的文件，您需要手动构建插件：

### 1. 构建项目
```bash
# 安装依赖
npm install

# 执行编译（生成 dist 目录）
npm run build
```

### 2. 加载到 Chrome
1. 打开 Chrome 扩展管理页面：`chrome://extensions/`
2. 开启右上角的**「开发者模式」**
3. 点击**「加载已解压的扩展程序」**
4. 选择项目根目录下的 **`dist`** 文件夹

### 3. 初始化配置
1. 右键点击插件图标 → **选项**，打开设置页面。
2. 默认情况下，插件已内化了反思模式和基础 Prompt。
3. 您只需添加您的 LLM 配置（API 地址和密钥）并保存。
4. 访问 B站 或 YouTube 视频页面，即可自动开始生成。

### 4. 使用说明

- **自动生成**：打开视频页面后自动开始
- **手动生成**：点击悬浮球可查看导图或手动触发生成
- **暂停功能**：点击工具栏图标可暂停/恢复自动生成

- 自定义 SVG 思维导图渲染器
- Chrome Extension Manifest V3
